TMD-26786 Custom Defined Tooltip for all Standard fields in Location details page
## Test Steps
1. Go to Settings-> Field Management -> Field Properties
2. Filter 'Tooltip' for 'Location' and 'Standard' for Type from drop-down menus
3. Add a custom tooltip for all standard fields and click 'Save' button (Do we need to fill all of Existing Standard Fields)
4. Go to Assets -> Locations and open an existing location. Verify if the custom defined tooltips are visible for all standard fields in Location details page.
5. Go to Assets -> Locations -> Add a Location and create a new location. Verify if the custom defined tooltips are visible for all standard fields in Location details page.

## Test Results
1. Field Properties page is loaded.
2. Results are filtered.
3. All custom tooltips are saved correctly in Field Properties page.
4. All defined custom tooltips for standard fields are visible in Location details page when hovering over the field itself.
5. All defined custom tooltips for standard fields are visible in Location details page when hovering over the field itself.
